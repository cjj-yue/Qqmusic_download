## 已落实

- 单独导出源码，不复用原项目的 Git 历史，不带个人歌单、日志、音乐、备份、账号或签名下载地址。
- 默认保存路径按当前用户计算；移除了专属于原机器的 Python / Node 路径及旧任务启动脚本。
- 保留完整功能；界面读取当前账号改为明确勾选，命令行交互模式使用 `--use-account`。切换访问方式会清除音质检测结果。
- 会话候选只接受与客户端当前账号配置匹配的账号；无法确认时不使用其他历史候选。凭据仅用于固定官方 HTTPS 请求，拒绝跟随重定向。
- 记录解码模块上游提交、许可声明、文件校验值和本地修改范围；整体采用 GPL-3.0-or-later，并保留第三方材料。
- FFmpeg 和 Node 改为使用者独立安装，构建脚本不把它们包入 EXE，避免沿用旧包不完整的分发材料。
